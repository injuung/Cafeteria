| `식단표/2025년~2026년/*.xlsx` | 월별 식단표 14개. 납품처에 나가는 형태. |

## 중간 산출물 (`python -m src.main pipeline` 이 만든다)

| 파일 | 만든 단계 | 내용 |
|---|---|---|
| `raw.json` | step1_parse | 파싱 원본. 편성 3,901건, 자재사용내역, 알레르기, 중량, 메모, EA |
| `groups.json` | step2_group | 표기명 → 레시피 ID 매핑 (762 ID / 87 별칭 그룹) |
| `master.json` | step3_tag | 태깅 완료 마스터. 단백질·조리방식·완제품·알레르기·자리분포 |
| `days.json` | build_days | 분석용 일자별 슬롯 테이블 (`analyze` 가 만든다) |

이 4개는 **지워도 된다.** `pipeline` 을 다시 돌리면 원천 엑셀에서 그대로 복원된다.
저장소에 같이 넣어 둔 이유는 클론 직후 `plan` / `analyze` / `verify` 를 바로 돌려볼 수 있게 하기 위해서다.
