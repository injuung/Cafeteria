# GitHub 에 올리는 법

이 폴더는 **이미 git 저장소로 초기화되어 있고, 첫 커밋과 원격 주소까지 설정된 상태**다.
아래 한 줄만 실행하면 된다.

```bash
cd 키즈락_식단표생성기_src/repo
git push -u origin main
```

처음 푸시할 때 GitHub 로그인 창이 뜨면 본인 계정으로 인증하면 된다.
(토큰 방식이면 Settings → Developer settings → Personal access tokens 에서
`repo` 권한 토큰을 만들어 비밀번호 자리에 붙여넣는다.)

## 상태 확인

```bash
git log --oneline      # 커밋 1개가 보여야 한다
git remote -v          # origin  https://github.com/injuung/Cafeteria.git
git status             # nothing to commit, working tree clean
```

## 원격 주소를 바꾸려면

```bash
git remote set-url origin https://github.com/<계정>/<저장소>.git
```

## git 이 없다면

Windows: https://git-scm.com/download/win 에서 설치 후 `Git Bash` 로 위 명령 실행.

## 무엇이 올라가고 무엇이 빠지는가

`.gitignore` 에 따라 **고객사 원천 데이터와 생성물은 올라가지 않는다.**

| 올라감 | 빠짐 |
|---|---|
| `src/` 전체 코드 | `data/생산일지/`, `data/식단표/` (원천 엑셀) |
| `README.md`, `requirements.txt` | `data/*.json` (중간 산출물) |
| `docs/` 명세·룰 문서 | `output/*.xlsx` (생성된 초안) |

코드만 공개해도 되지만 원천 엑셀은 더바른푸드 자료이므로 저장소가 **public 이면
data 폴더는 절대 커밋하지 않는 게 맞다.** 지금 설정이 그렇게 되어 있다.

## 받은 쪽에서 돌리는 법

```bash
pip install -r requirements.txt
# data/생산일지/ 아래에 월별 생산일지 xlsx 를 넣고
python -m src.main pipeline
python -m src.main plan 2026-11
```
