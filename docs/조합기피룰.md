## 룰별 근거

### [C01] 붉은 고기 국 + 붉은 고기 메인 금지
- 적용대상: both / 강도: hard
- 관측: 소고기맑은국 × 돈육메인 기대 8.8회 → 관측 0회 (P<0.001); 소고기국 × 우육메인 기대 5.9회 → 관측 0회 (P=0.003)
- 이유: 국에서 이미 고기 국물을 먹는데 메인까지 붉은 고기면 한 끼의 지방·나트륨이 몰린다. 유아는 한 끼 섭취량이 적어 채소·곡류를 밀어내고, 성인은 물리는 식단이 된다.

### [C02] 국과 메인의 주단백질 동일 금지
- 적용대상: both / 강도: hard
- 관측: 우육국×우육메인 기대 9.1회 → 0회; 계육국×계육메인 기대 3.7회 → 0회
- 이유: 같은 단백질이 두 번 나오면 알레르기 노출이 겹치고, '오늘 급식은 다 닭이었다'는 인상이 남는다. 유아식은 한 끼 안에서 단백질 종류를 나눠 먹이는 편이 좋다.

### [C03] 메인 자리에 국물 요리 금지
- 적용대상: both / 강도: hard
- 관측: 258일 중 메인이 국물류인 날 0일
- 이유: 국이 이미 편성돼 있어 국물이 두 그릇이 된다. 유아는 국에 밥을 말아 국물만 먹고 반찬을 남기기 쉽다.

### [C04] 찬 채소 반찬(무침·샐러드) 2개 금지
- 적용대상: both / 강도: hard
- 관측: 서브 무침 + 샐러드 동시 편성 기대 12.4회 → 관측 0회 (P<0.001)
- 이유: 둘 다 차고 물기 있는 생채소라 식감이 겹친다. 유아는 생채소 수용도가 낮아 두 개 다 남길 위험이 크고, 배식 온도 관리도 따뜻한 반찬이 하나는 있어야 한다.

### [C05] 서브 자리 조림 + 구이 동시 금지
- 적용대상: both / 강도: soft
- 관측: 서브 구이 + 조림 기대 5.1회 → 0회 (P=0.006); 서브 면 + 조림 기대 4.8회 → 0회 (P=0.008)
- 이유: 조림은 간장·물엿으로 달고 짜고, 구이도 양념이 배어 있어 간이 센 반찬이 둘이 된다. 유아 급식 나트륨 기준을 넘기기 쉽다.

### [C06] 면 요리 + 면·떡 국 금지
- 적용대상: both / 강도: hard
- 관측: 면 포함 16일 중 면·떡국과 겹친 날 2일뿐, 나머지는 맑은국·된장국
- 이유: 탄수화물이 밥·면·떡으로 세 겹이 된다. 유아는 부피감에 먼저 배가 불러 단백질 반찬을 남긴다.

### [C07] 유아식 매운 재료 2개 금지
- 적용대상: kid / 강도: hard
- 관측: 258일 중 매운 재료가 1개라도 들어간 날 3일(1.2%), 2개인 날 0일
- 이유: 유아식은 고춧가루·고추장 자체를 거의 쓰지 않는다. 매운맛은 성인식에서 접두어(매콤·얼큰)를 붙여 분리하는 것이 이 사업장의 실제 운영 방식이다.

### [C08] 마른 조리(튀김·구이·전) 3개 이상 금지
- 적용대상: both / 강도: soft
- 관측: 하루 같은 조리방식 3회 반복은 258일 중 5일(1.9%)
- 이유: 기름진 조리가 몰리면 한 끼 지방 비율이 올라가고, 유아는 목이 메어 국물에만 손이 간다. 물기 있는 반찬이 하나는 필요하다.

### [C09] 닭 국 + 무침 2개 금지
- 적용대상: both / 강도: soft
- 관측: 닭 국 × 무침 서브 기대 5.3회 → 관측 1회
- 이유: 삼계탕·닭개장류는 그 자체로 한 끼를 지탱하는 국이라 곁들임은 따뜻한 볶음·조림 쪽으로 붙는 것이 실제 편성 패턴이다.
